# Fonts

Both families are licensed under the SIL Open Font License 1.1, which permits
bundling and redistribution inside a game.

- **Archivo** — voice type (titles, names, buttons, labels).
  https://fonts.google.com/specimen/Archivo
- **JetBrains Mono** — every figure a player compares: room code, scores,
  round pot, live dice count.
  https://fonts.google.com/specimen/JetBrains+Mono

Static instances pulled from Google Fonts at the weights the design uses
(Archivo 400/500/700/800, JetBrains Mono 400/700). Weights are separate files
rather than variable fonts so Godot picks the right one without axis setup.
